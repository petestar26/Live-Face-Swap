KEY FACTS / GOTCHAS (these cost me hours before - please respect them)
- Python MUST be 3.10 (64-bit). NOT 3.11/3.12/3.13 (the wheels break).
- insightface 0.7.3 will try to COMPILE and FAIL without a prebuilt wheel.
  Install the bundled one, do NOT build from source:
    venv\Scripts\python -m pip install --no-deps wheels\insightface-0.7.3-cp310-cp310-win_amd64.whl
  If wheels\ is missing, tell me - we'll get a prebuilt cp310 win_amd64 wheel.
- For GPU acceleration, after installing requirements also run:
    venv\Scripts\python -m pip install nvidia-cudnn-cu12
  (onnxruntime-gpu needs cuDNN.) You do NOT need to hand-install CUDA Toolkit.
- VERIFY the GPU is visible before continuing:
    venv\Scripts\python -c "import onnxruntime as ort; print(ort.get_available_providers())"
  I must see CUDAExecutionProvider. If only CPUExecutionProvider shows, fix the
  NVIDIA driver / cuDNN first (it will be unusably slow on CPU).
- Prerequisites to install FIRST: Python 3.10 (tick "Add to PATH"), latest
  NVIDIA driver (then restart), Visual C++ Redistributable x64.
- Environment setup (if doing it manually instead of INSTALL.bat):
    python -m venv venv
    venv\Scripts\activate
    python -m pip install --upgrade pip
    pip install --no-deps wheels\insightface-0.7.3-cp310-cp310-win_amd64.whl
    pip install -r requirements.txt
    pip install nvidia-cudnn-cu12
- Launch: python run.py --execution-provider cuda
- MODELS (must be in the models\ folder):
    inswapper_128.onnx, inswapper_128_fp16.onnx, GFPGANv1.4.pth,
    GPEN-BFR-256.onnx, GPEN-BFR-512.onnx
  They are git-ignored, so if I cloned from GitHub they'll be MISSING and must
  be copied from my transfer folder (or downloaded). inswapper_128_fp16.onnx:
  https://huggingface.co/hacksider/deep-live-cam/resolve/main/inswapper_128_fp16.onnx
  GFPGANv1.4.pth:
  https://github.com/TencentARC/GFPGAN/releases/download/v1.3.4/GFPGANv1.4.pth
